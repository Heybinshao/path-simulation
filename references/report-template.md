# 产出物模板

> 每条路径模拟结束后按此模板输出报告。

每条路径模拟结束后输出：

```
## 路径模拟报告

### 测试对象
<skill/workflow 名称 + 版本>

### 覆盖路径
标准 / 跳过 / 中断 / 分批 / 反悔 / 异常 / 跨文件（勾选实际走的）

### 问题清单
| # | 路径 | 问题 | 严重度 | 哪步卡 | 为什么 | 建议修复 |
|---|------|------|--------|--------|--------|---------|
| 1 | 标准 | 检查步骤排在写入后 | 🔴 阻断 | 第 4 步 | 时序错位 | 移到第 2 步前 |

严重度：🔴 阻断（主干路径卡死 / 必出错）> 🟡 一般（分支歧义 / 偶发卡顿）> 🟢 建议（优化项，不阻断）。颜色随文字进表（与 skill-acceptance-report-schema 同口径），按爆炸半径排序，先报阻断。

走查轨迹（每条路径必填，含无问题路径）：记录「走到第 X 步，第 Y 步判断无卡点」。无问题的路径也要留痕，作为走查可审计的轨迹——防漏走、可复盘。

结尾必须带：**共发现 N 个问题。是否修复？**（等使用者决定，不自动修）

### 使用者决定
<「修」/「只修 X」/「都不修」——记录使用者确认内容>

### 修复记录
- 修复了哪几条、怎么修的
- 修复后重走路径：标准 ✅ / 跳过 ✅ / 中断 ✅
- 新路径（异常）发现新问题：无 → 停止

### 沉淀
- 是否回写陷阱表：是（<skill> 表 +N 条）/ 否（使用者拒绝）

### 结论
<通过 / 未通过 + 剩余问题>
```
