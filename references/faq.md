# 常见问题（FAQ）

**Q: 我改的是一个很小的脚本，也要走 3 条路径吗？**
A: 越小越要快——3 条路径 5 分钟走完（至少含标准 + 1 条风险路径：异常/跨文件优先）。问题是"有没有走"，不是"走了几条"。

**Q: 我是人类，不是 agent，怎么"模拟执行"？**
A: 把步骤念出来，假装自己是第一次用的用户，每一步问「我现在该干什么？我知道吗？」。卡住的地方就是文档没写清的地方。

**Q: 路径模拟和实际测试有什么区别？**
A: 实际测试跑真实环境；路径模拟在脑子里/纸面上走。路径模拟便宜（零成本），能发现大部分流程问题，剩下的交给真实测试。

**Q: 脑走查靠作者自己，抓得到盲点吗？**
A: 抓得到明显的断点，抓不到真实外行会撞的微妙断点——作者最知道意图，最容易在脑子里「让它走通」。所以：脑走查抓广、实跑抓深。关键路径（主干 + 高风险分支）建议让一个真外人 / 真 agent 实跑一遍，弥补作者自带意图的盲点。路径模拟是廉价广覆盖的 flow 走查，不是测试的替代品。

**Q: 走完 3 条路径没发现问题，能保证没问题吗？**
A: 不能。但"换一条新路径不再发现问题"是合理的停止点——继续走边际收益递减。注（v2.6 起）：停止判据以步骤 8「分级停止」为准——仅剩「建议」级且各有处置才算收工；多参考文件对象收工前必须至少走过一次跨文件路径 #7。
