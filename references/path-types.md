# 8 条路径来源清单

> 路径模拟的入口选择参考。执行时至少走 3 条不同路径，且必须覆盖：标准路径 + 至少 1 条风险路径（异常路径 #6 或跨文件路径 #7 优先）。跳过/中断/反悔/分批本质都是「用户不按线性走」的同类扰动，只走它们会漏掉正交的高风险轴。**会话回放是路径来源（取材法）而非独立路径类型**——3 条配额与风险路径要求照常，不可用回放顶替 #6/#7。

## 路径来源一：用户指令（经典 7 条）

| # | 路径 | 描述 | 典型用户话术 |
|---|------|------|-------------|
| 1 | 标准路径 | 按文档预期完整走一遍 | 「帮我做 X」 |
| 2 | 跳过路径 | 跳过一个前置步骤直接要结果 | 「直接给我结果，不用检查」 |
| 3 | 分批路径 | 任务拆成多次、中间夹其他请求 | 「先做 A」「顺便记一下 B」「继续 A」 |
| 4 | 中断路径 | 中途插入新指令打断原流程 | 「等一下，先处理这个」 |
| 5 | 反悔路径 | 执行到一半要回退 | 「那条别删」「恢复刚才改的」 |
| 6 | 异常路径 | 输入缺失/格式错误/环境不满足 | 「文件不存在」「没装依赖」 |
| 7 | 跨文件路径 | 多文件/多步骤协同场景 | 检查参考文件之间是否矛盾 |

**#7 跨文件路径的执行定义（不是「扫一眼」，是判据配对）**：

1. 提取**跨文件重复出现的可执行判据**——命令/字段名、数值/上限、「必做/禁用/正常/可跳过」类范围声明；只在单文件出现的判据不进对账。
2. 同名判据逐对**双向**比对方向与数值：A 文件允许、B 文件禁止 = 必有一错或缺边界裁决。**必含 SKILL.md 主流程 ↔ references 双向**（执行者先读正文再跳参考，两边打架最致命）。
3. 收工判据：每条判据对有结论（一致 / 冲突 / 合法历史残留已标注）。
4. 深版枚举方法见 skill-health-audit 8g（如安装，属静态体检权威版）；**未装时按本节 1-3 独立执行，不依赖对方**。

## 路径来源二：会话回放（被测对象是 agent 判断流程/自动化管线时用）

被测对象不是「用户从 A 到 B 的操作流程」，而是 agent 自己的判断链（记忆管线、审计流程、自动写入闸门等）时，「用户指令」可以是**真实发生过的事件序列**——从最近的会话记录里取材回放：

- 取材原则：挑真实发生过的事故/扰动场景（并行写入、中途打断、误操作恢复），比虚构入口更毒辣——虚构场景测「设计是否合理」，回放场景测「设计是否经得住现实」
- 回放方式：按事件时间线逐步重演 agent 的每步决策，问「按 skill 的规范，这一步该怎么做？实际做了什么？两者差异是 bug 还是纪律缺失？」
- 实例（2026-08-24）：memory-file-maintenance 升级基线机制后的两轮自检，全部用当天真实事故（基线失灵、并行写入、误删恢复）当测试素材，比套用经典 7 条更有效
- **环境兜底（无会话记录可回放时——第三方安装/新环境/会话历史已清）**：降级为「自构造事故序列」——按被测流程的已知失败模式（并行、中断、误操作）编造事件时间线走回放法其余步骤；报告注明取材方式为自构造而非真实事件，证据强度降级
